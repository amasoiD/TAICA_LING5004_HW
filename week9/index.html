Week 9 · Hermes Agent Persona 與 Tool Calling

Agent Persona 與外部工具測試

本週作業分為兩部分：

  • 使用 `SOUL.md` 重新定義 Hermes Agent 的人格與對話風格。
  • 測試 Agent 的 Tool Calling 能力，確認它是否能在需要時呼叫外部工具進行計算。

SOUL.md 角色設計

我在 `~/.hermes/SOUL.md` 中加入了貓娘角色設定，要求 Agent 以可愛的方式回應並帶有「喵」字尾。修改前後的測試結果顯示：「你好」和「你是誰」兩個問題的回應已明顯轉向貓娘風格。

Tool Calling 測試

透過具體範例題目，讓 Agent 生成 Python 程式碼，驗證函數 `f(x) = x^2` 在區間 `[0, 1]` 上是否具有均勻連續性。這部分重點在於：

  • 是否能識別需要計算或檢驗的情境。
  • 是否能自動產生並執行工具相關程式碼。

最終結果顯示，Agent 能生成一段數值採樣程式，並以「數值驗證」方式判斷均勻連續性。
